# README visuals / 项目配图

`viewer.png` and `management.png` are native RustView v0.6.3 screenshots captured on Windows. They show sample RAWs from Nikon Z6, Canon EOS R, Sony a7 III and iPhone 12 Pro. The original photographers dedicated these samples to the public domain under CC0 1.0. [Sample files and license](https://github.com/tellodaniel/revelraw-sample-raw-files) · [raw.pixls.us](https://raw.pixls.us/)
