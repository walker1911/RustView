# README visuals / 项目配图

`qr-recognition.png`, `ocr-selection.png`, and `ocr-result.png` are cropped native RustView v0.6.8 screenshots captured on Windows at 125% scaling. They show an automatically detected QR code, a text selection, and the extracted Chinese and English text. The test image contains synthetic text and a QR code that points to `example.com`.

`qr-recognition.png`、`ocr-selection.png` 和 `ocr-result.png` 是 RustView v0.6.8 的 Windows 原生截图，拍摄于 125% 显示缩放，并裁切出功能区域。三张图分别显示自动识别的二维码、框选文字区域和提取出的中英文文字。测试图使用合成文字和指向 `example.com` 的二维码。

`viewer.png`, `viewer-controls.png`, `photo-soft-focus.png`, `floating-toolbar.png`, and `management.png` are native RustView v0.6.7 screenshots captured on Windows at 125% scaling. They show sample RAWs from Nikon Z6, Canon EOS R, Sony a7 III and iPhone 12 Pro. The original photographers dedicated these samples to the public domain under CC0 1.0. [Sample files and license](https://github.com/tellodaniel/revelraw-sample-raw-files) · [raw.pixls.us](https://raw.pixls.us/)
