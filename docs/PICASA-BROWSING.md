# 图片浏览说明 / Browsing guide

v0.4.0 完整离线预发布版增加了方向键翻图和底部封面浏览。运行包中的 `RustView.exe`，打开一张图片，或在管理列表中选中图片后按 Enter 进入查看。

| 操作 | 行为 |
|---|---|
| ← / → | 上一张 / 下一张，首尾不循环、不重复读取当前图 |
| ↑ / ↓ | 平滑放大 / 缩小 |
| 点击底部封面 | 切换到对应图片 |

底部采用平直的 Picasa 式胶片带，没有倾斜、透视或梯形变形；缩略图保留照片比例并留出间距。当前项居中、最大、最清晰；越远的图片适度缩小、逐渐透明。底部显示当前文件名和 `1/84` 形式的序号，顺序与当前排序、筛选和多选批次一致。只有一张图片时不占用底部高度。

本次修订保留连续翻图时的运动惯性，反向时平滑转向，边缘封面渐隐；Home/End 等远距离跳转使用短交接，避免整排硬切。

读取下一张时，先沿用上一张正常显示的概览，并标明正在读取的文件。目标图自己的低清预览到达后才切换，清晰图就绪后直接替换。快速反向翻图、取消和切换来源会丢弃过期预览。目标图的复制、编辑和删除需等待相应图像就绪，或回到管理模式操作。

管理模式中的方向键继续移动网格选择。文本框、密码框、菜单、比较和编辑窗口保留自身按键。已有快捷键和鼠标滚轮继续可用；自定义快捷键优先。如果导入过完整的旧快捷键配置，新方向键可能被该配置禁用，可在快捷键设置中重新绑定。

运行依赖已包含，不需要首次联网。设置和目录库保存在这份试用包旁的 `RustView-data` 中。

本次还加入 [PSD/PSB 合成图查看](PSD.md)。如要用作主力看图软件，可双击包内 `Setup-File-Associations.cmd` 注册图片候选关联和 ZIP／RAR／7z 右键入口；最终默认程序在 Windows 设置里确认，卸载使用 `Remove-File-Associations.cmd`。详见 [文件关联说明](WINDOWS-INTEGRATION.md) 与 [Rust 看图软件调研及后续取舍](RUST-VIEWER-COMPARISON.md)。

大PSD修订支持本地以及ZIP／RAR／7z内大于512 MiB的PSD/PSB，源文件或所选条目最多64 GiB。包内只自动提取所选项到私有临时盘，完成或取消后清理；画布像素、内存、缓存与超时预算继续生效。画布在预算内时保留完整分辨率。大条目需要临时盘容纳该文件并保留2 GiB；后台预览避免重复提取同一大PSD。具体范围见上述PSD说明。

大型加密RAR已补测文件内容加密和文件名加密，含物理体积超过512 MiB的包。读取中退出会先取消任务、等临时文件和读取进程清理后关闭；等待期间不会再派发缩略图或其他新读取。普通关闭图片返回管理模式的快捷键行为保留。

封面预览按需生成，未准备好时显示占位。后台预览失败由正常看图流程在打开目标后处理。封面纹理最多 32 张、每张 128×128，约 2 MiB RGBA，配套低清像素最多约 512 KiB。连续翻图复用上一张图的已有概览纹理，另保留一张属于当前目标、最大 64×64 的低清预览。独立预览进程树上限 512 MiB、30 秒，慢读取超过 150 毫秒时优先补当前目标预览。主图工作进程树上限为 2 GiB，GPU 细节纹理上限为 256 MiB。

最近看过的静态图片按内存预算缓存，适用于当前文件夹或压缩包。按 `Alt+O` 打开「选项与快捷键」，可查看本机推荐值或设置 0–2048 MiB，设为 0 可关闭。点击「保存选项与快捷键」后，下次启动会沿用设置。

本地窗口捕获接口返回超时；已通过绘图、布局和点击逻辑测试，真实窗口的视觉效果仍需试用检查。具体实施与验证记录见 [规划文档](PLAN-PICASA-BROWSING.md)。
