# RustView v0.6.1 / 更新说明

## 中文

RustView 启用正式莲花图标。冷黑渐变与彩色花瓣用于 Windows 程序、主窗口和中英文项目首页。程序内置多种尺寸的图标，供资源管理器和 Windows 文件关联显示。

下载 Windows x64 完整离线 ZIP，解压到可写文件夹，双击 `RustView.exe` 或 `Start-RustView.cmd`。包内已含 7-Zip、LibRaw、ImageMagick、ExifTool 和 VC++ 运行库，首次启动也可离线。升级前请备份原程序旁的 `RustView-data`，其中有设置、目录库和处理记录。[离线 ZIP](https://github.com/walker1911/RustView/releases/download/v0.6.1/RustView-0.6.1-win-x64-offline.zip) · [SHA-256 校验文件](https://github.com/walker1911/RustView/releases/download/v0.6.1/RustView-0.6.1-win-x64-offline.zip.sha256)

## English

RustView now uses its official lotus icon. The artwork pairs colorful petals with a subtle, cool black gradient and appears in the Windows executable, the main window, and both project READMEs. The executable embeds multiple icon sizes for File Explorer and Windows file associations.

Download the complete Windows x64 offline ZIP, extract it to a writable folder, and double-click `RustView.exe` or `Start-RustView.cmd`. It includes 7-Zip, LibRaw, ImageMagick, ExifTool, and app-local VC++ runtime libraries for offline use from first launch. Before upgrading, back up the `RustView-data` folder beside the old executable to keep your settings, catalog, and processing records.
