# 在图片上选字

## 交互依据

微信电脑版的图片预览提供「提取文字」和复制功能。公开资料确认了入口与复制能力，具体到逐字拖选和快捷键，RustView 按本方案定义。图片内拖选并复制到其他应用也是桌面实况文本的常用交互。[微信电脑版功能报道](https://developer.cloud.tencent.com.cn/news/949593) · [Apple 桌面实况文本操作](https://support.apple.com/zh-cn/guide/safari/ibrw20183ad7/27.0/mac/27)

## 操作流程

1. 图片显示后，停留至少 650 毫秒并等看图任务空闲，RustView 在后台离线识字。整图 OCR 和框选 OCR 仍可在右键菜单调用。
2. 鼠标移到识别出的文字上时显示文本光标，以淡下划线提示所在行。按住左键从某个字拖到另一个字，选区按阅读顺序延伸，可正向、反向或跨行拖选。只有选中文字加半透明高亮。空白处仍可直接拖动平移。
3. `Ctrl+C` 或右键「复制所选文字」将选区写入系统剪贴板，可在聊天框、记事本等文本框中按 `Ctrl+V` 粘贴。鼠标在文字上或已有选区时，`Ctrl+A` 选择本图全部已识别文字。
4. 滚轮可缩放，高亮随图片缩放、平移和旋转。点击空白或按 `Esc` 清除选区，之后可再次直接拖选。切图或关窗会清除旧图的选字状态，并取消未完成的识别。

## 实现范围

复用现有离线 OCR 工作进程和像素预处理。自动识字最多同时处理一张图，输入最长边 1,800 像素且最多 200 万像素，子进程限额 256 MiB，超时 8 秒。按住方向键连续翻图、目录扫描和图片解码优先。Tesseract 的 hOCR 字符框提供每个已识别字符的位置，坐标映射到原图像素，再用同一套看图变换绘制选区和定位鼠标。复制沿用 OCR 阅读顺序与换行，极小字和复杂排版的效果取决于识别结果，可用手动框选针对局部文字进行识别。[Tesseract 字符框说明](https://github.com/tesseract-ocr/tesseract/blob/main/doc/tesseract.1.asc#output-format-parameters)

## 验证

- 用普通 PNG、透明底浅色中文字和中英混排图检验识别结果与坐标对齐，复查原有整图、框选入口。
- 在 Windows 上验证无需菜单即可选字，测试单行、跨行、复制粘贴、空白处平移、缩放、旋转、切图和 `Esc` 清除选区。
- 对照上一版实测首图与连续翻图的耗时和内存。检查识别任务在停止翻图后才启动，切图时旧结果不会覆盖新图，关窗后工作进程清理完成。
